# 软件详细设计交付目录

本文件夹沿用项目编号报告的组织方式，主报告与配套设计资料分别保存。

- **5详细设计报告.docx**：按样例附录C编写的主报告，含引言、支撑环境、11个主部件、34个二级部件、公开操作、流程、事务、异常及用例追踪。
- **部件设计/**：已有部件详细设计说明书及原架构图的归档副本；原文件保持不变。
- **顺序图/**：12个主用例、3个还款分用例和2个内部流程，共17张完整顺序图；含PNG、SVG、PlantUML、索引及HTML预览。
- **报告插图/**：正文使用的20张主交互顺序图及1张部件架构图；PNG与SVG用于报告，PlantUML保留主交互图源。

主报告统一使用部件设计中的UC-01至UC-12编号，需求报告原UC-09至UC-11的对应关系在3.14节说明。正文图便于打印阅读，完整异常与参与者见顺序图目录。当前ER缺少的版本、授权、阅读确认、分期利息费用等信息在3.14节明确列为设计补充，不表示这些字段已经存在。

模板来源为资料/原来的模板.docx中的附录C；该文件与此前的软件项目报告样例文档为同一哈希内容。排版检查用的PDF、页面图与构建脚本保存在_work/detail_report，不属于本文件夹交付内容。
