## 项目内容

- [可行性分析报告](1.可行性分析报告/1可行性分析报告.docx)：项目背景、业务目标与可行性。
- [后端技术选型报告](2.后端技术选型报告/2后端技术选型报告.docx)：后端技术路线与实现基线。
- [需求分析报告](3.需求分析报告/3需求分析报告.docx)：用户界面、用例和功能需求。
- [概要设计报告](4.概要设计报告/4概要设计报告.docx)：六模块结构、类与数据库设计。
- [详细设计报告](5.详细设计/5详细设计报告.docx)：11个主部件、34个二级部件、52项公开操作及事务和异常处理。

详细设计目录附有17张完整顺序图及PNG、SVG、PlantUML源文件；正文使用的主交互图单独保存在“报告插图”中。查看[详细设计目录说明](5.详细设计/README.md)和[顺序图索引](5.详细设计/顺序图/顺序图索引.md)可定位相关文件。

文档处理脚本、解析结果和排版检查预览保存在本地 `_work/`，不纳入仓库。
